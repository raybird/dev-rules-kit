> 本 skill 依據 `docs/AGENTS.md` **1.17**。專案的該檔版本低於此值、或引用的章節不存在或語意不符時，依「核心層齊備性檢查」明確說出缺什麼並停下來問，不得自行套用預設值繼續。

規範文件的效果取決於 agent **是否在該讀的時候讀到、讀到後是否照著做**。這兩件事由措辭與位置決定，與內容正確與否無關——一條寫得完全正確的規則，放錯位置或用錯語氣就等於不存在。

## Pointer：決定何時被讀到

**pointer** 是常駐在 context 裡、指向 context 外材料的那一行：skill 的 `description`、`AGENTS.md` 裡指名某份文件的句子，都是同一種東西。

**決定觸發時機的是 pointer 的措辭，不是它指向什麼。** 必讀的材料配上模糊的 pointer，就是一個變異來源：有時讀到、有時沒讀到，而且兩者都不報錯。先把措辭寫銳利；銳利不起來，才把材料搬回 in-file。

pointer 要同時寫出兩件事：**材料是什麼**，以及**哪些分支該觸發它**（分支＝這份材料處理的一種不同情況）。同義詞把同一個分支寫兩次，合併成一條。

pointer 每回合都在花 token，因此比正文更值得刪：把觸發詞放句首，刪掉正文已經承載的身分描述。

## 位置：in-file 還是 disclosed

三個層級，依「agent 多快需要它」排序：

1. **In-file step**——agent 依序執行的動作，主層級
2. **In-file reference**——隨查隨用的定義與規則
3. **Disclosed reference**——推到獨立檔案，由 pointer 觸發載入

**Branching 測試**決定該放哪層：**每條分支都需要的留 in-file，只有部分分支會走到的推到 pointer 後面。**

**過長本身就是失效**——即使每一行都有效、都不重複。注意力會在多餘的篇幅上變薄，而且每多一行就多一行要維持相關性。當一份文件同時有 steps 與 reference，該被推出去的 reference 會把 steps 埋掉，讀到它們變成擲硬幣。

**共置**是同一層內的配套：一個概念的定義、規則與例外放在同一個標題下，讀到一部分就會帶出鄰近的部分。（這與重複不同：重複是同一個意思出現在兩處，散置是同一個意思被拆到多處。）

## 正面表述

**直述目標行為。** 以禁令操控行為會把被禁的行為拉進 context，反而讓它更容易被觸發——禁令是弱修飾詞，會被它所啟動的概念蓋過去。

無法正面表述的硬護欄可以保留，但要配上正面目標，讓注意力落在該做的事上。改寫時特別注意**把錯誤流程完整描述一遍**的句子，那是這個失效模式最重的形態。

## 完成判準

每個步驟都以完成判準收尾，它有兩個性質：

- **清晰度**——agent 能不能分辨做完與沒做完。模糊的界線會招來**提早結案**：注意力滑向「結束」本身。
- **強度**——要求多高。「每個受影響的模組都已列出」會逼出實際工作，「產出一份清單」不會。強度不限於步驟：「每條規則都已套用」同樣能為一整段 reference 設下窮盡標準。

**看得見的後續步驟會產生提早結案的拉力，判準的清晰度是唯一的阻力。** 防守順序是先把判準寫銳利；只有在判準本質模糊**且**確實觀察到搶著結束時，才拆開序列——而藏起後續步驟只在跨越真實 context 邊界時有效（交接或 subagent 派工；inline 呼叫會把後續步驟留在同一個 context 裡，什麼都沒清掉）。

最強的判準同時可檢查且窮盡。

## 用詞

優先選**模型預訓練裡已經有的概念詞**（tracer bullet、seam、red、fog of war），它們免費帶來一整片語意。自創詞可行，但要用定義 token 買下預訓練本來免費給你的東西——自創前先找有沒有既有的詞。

重複的是**詞**，不是句子：同一個詞在正文與 pointer 反覆出現會累積出分散式定義；同一個意思寫成三種說法只是散置。

## 修剪

- **單一真相來源**：一個意思只在一處權威定義，改行為時只改一處。
- **環境也是真相來源**：`package.json`、設定檔、目錄結構、`--help` 都是。文件複述它們等於做了一份快取，只有在查詢昂貴時才划算。值得寫下的是查不到的東西：沒寫成文的慣例、選擇背後的理由、設定檔不會承認的地雷。
- **相關性**：這一行還對這份文件要做的事有影響嗎？失去相關性的方式有兩種——從來就沒影響，或者它描述的世界變了。
- **no-op 測試**：這句話跟模型的預設行為有差別嗎？**判準是相對於模型，不是相對於讀者**——兩個人對某句是不是 no-op 有歧見，其實是對預設行為有歧見，**靠跑一次文件解決，不靠辯論**。判定為 no-op 時刪整句，不是修字。

## 本 kit 的額外約束

- **核心層字串維持原樣**：狀態字串、metadata 欄位名、章節名依 `docs/AGENTS.md`「客製邊界與同步策略」，改名等同拿掉一道 gate 且不會報錯。
- **雙語同步**：`rules/AGENTS.md` 與 `rules/AGENTS.zh-TW.md` 一起改，`## ` 章節數保持相等。
- **改完跑同步**：`python3 scripts/sync-skills.py` 後以 `--check` 驗證。

## Completion Gate

- 每個新增或改寫的段落，都答得出「哪些分支需要它」；只有部分分支走到的，已放在 pointer 後面。
- 新增的指令以正面表述寫成；保留的禁令是無法正面表述的硬護欄，且已配上正面目標。
- 每個新增步驟都有可檢查的完成判準，其強度與該步驟要逼出的工作量相稱。
- 新增的自創詞都經過「有沒有既有的詞可用」的檢查，並在首次出現處定義。
- 逐句通過 no-op 測試；無法判定時記錄下來，由實跑而非辯論解決。
- 涉及本 kit 檔案時，核心層字串未改名、雙語章節數相等、`--check` 通過。
