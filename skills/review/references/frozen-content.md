# 記帳區段裡的凍結內容

`scripts/verify-artifact.py` 判需重審、指出記帳區段的某一行時讀本檔。可以改的範圍與沿用條件見專案 `docs/agents/review-evidence.md`「審查之後的提交」；本檔只列記帳章節（`## Timeline`、`## 待確認事項`、`## Gate 豁免紀錄`，流程契約 2.5 起加 `## 現況`）裡哪些寫法仍視為凍結內容，判定以 verify-artifact 為準。

## 視為凍結的行

- 看起來像標題的行，包括緊接在文字後的 `===`、`---`。
- code fence。
- 以粗體開頭的行，包括多層引用、清單與編號清單裡的寫法。待確認事項、Gate 豁免紀錄的節內有標題、code fence 或粗體開頭的行時，整節新增或刪除的判定無效；`## 現況` 節內的標題、code fence 與 `**現行 review**` 以外的粗體開頭行同樣凍結。
- 以 `[` 開頭的行，包括引用與清單裡的；連結參照定義的標籤可以跨行。只放行三種：`[ ]`、`[x]` 任務清單；獨佔一行的 GitHub alert（例如 `> [!NOTE]`）；同一行就關閉、後接 `(`、連結文字不含方括號與反斜線的連結（例如 `- [#4](網址)`）。
- 含 `<` 的行，code span 與反斜線跳脫裡的也算；只放行不在行首的 `<br>`、`<wbr>`。

## 跨行的開頭

沒有在同一行關閉的註解（`<!--`）、處理指令（`<?`）、宣告（`<!` 接英文字母）與 CDATA（`<![CDATA[`），到結束字串為止整段凍結，結束字串不含 `<` 的那一行也算。`<!-->`、`<!--->`、`<?>` 視為同一行就關閉。

這四種開頭在任何章節都追蹤：凍結章節（含 code span 裡）寫了沒有關閉的 `<?` 或 `<!` 接字母，其後的內容與章節都視為凍結，審查之後在後面補記也判需重審，錯誤訊息會指出開頭所在的行。凍結章節要提到時寫成文字，或寫完整（例如 `<?php ?>`）。

## 段落與表格

連結 title、code span 這類行內語法可以跨行，所以記帳章節裡含凍結內容的段落（連續的非空行）整段凍結。段落前接什麼（空行、標題或表格列）與怎麼結束（空行、下一個標題或檔尾）也列入比對；表格後面不空行時，段落會渲染成表格的一列，該表格的表頭與分隔列一併凍結。渲染相同的變化（例如在標題與段落之間補空行）同樣判需重審。新增的內容與含凍結寫法的段落之間空一行。

表格符合下列條件時各列分開判定，可以直接補列：空行或標題之後開始；表頭與分隔列都頭尾是 `|`；每格有空格以外的內容；空白只有一般空格；沒有反斜線；欄數相同。表格含凍結列時，表頭與分隔列一併凍結。其他寫法照段落處理。

## 空白與換行

凍結章節的比對包含空行，連續空行視為一個。分行只認換行字元；NBSP、U+2028 這類字元不算空白，也不算換行。
