fixture 由 [build_fixtures.py](build_fixtures.py) 建立，基準組以 v4.8.1、候選組以本分支的 kit 部署 `docs/` 並安裝技能，其餘內容相同。每個案例一個新 session，以 issue-0001 的 [run_case.py](../../issue-0001/fixtures/run_case.py) 執行。允許清單沒有列 Agent 工具，但實跑時 agent 仍能派 subagent（2026-11-03 28b2 實際派了重審），所以需要重審時可能真的執行重審，計數照「記帳觸發的重審」定義。

計數定義：

- **單獨回填提交**：該提交的 diff 只改 `**核准 commit**` 那一行。
- **記帳觸發的重審**：agent 判定只因保存報告或記錄決策就需要重新審查（宣告需要重審、嘗試重審或回報因此受阻都算）。
