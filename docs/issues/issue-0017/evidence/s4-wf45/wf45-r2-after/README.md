# Issue 3601 - 待辦到期日與逾期清單 (Small)

## 概述
待辦可以帶到期日；列出清單時，有到期日的待辦在標題後面顯示月/日；另外新增一個列出已逾期、還沒完成的待辦的指令。沒有到期日的待辦與既有 `todo.json` 資料維持原本的顯示。範圍不含修改或清除既有待辦的到期日、提醒通知、排序與年份顯示。

## 涉及檔案
- `todo.py` - `add` 解析到期日並存入項目；`render` 顯示月/日；新增 `overdue` 指令
- `test_todo.py` - 新增 AC-1～AC-4 的測試
- `README.md` - 使用說明補上到期日與 `overdue`（常青文件，依 project.md）

## 驗收條件

1. **AC-1**：`python3 todo.py add 寫週報 --due 2026-12-05` 新增一筆標題為「寫週報」、到期日 2026-12-05 的待辦；不帶 `--due` 時行為與現在相同 — 檢查方式：在暫存目錄執行指令後讀 `todo.json`，或以 unittest 呼叫 `main`
2. **AC-2**：`python3 todo.py` 列出清單時，有到期日的待辦在標題後面加一個空格與不補零的月/日，例如 `[ ] 2. 寫週報 12/5`；沒有到期日的待辦（含既有、沒有到期日欄位的 `todo.json` 資料）輸出與現在相同 — 檢查方式：unittest 以固定項目比對輸出字面值，既有 `test_render_marks_done` 維持通過
3. **AC-3**：`python3 todo.py overdue` 只列出到期日早於今天（系統本地日期）且未完成的待辦，格式同 AC-2；今天到期、未來到期、已完成與沒有到期日的待辦都不列出；沒有符合的待辦時不輸出任何內容 — 檢查方式：unittest 注入固定的「今天」，以涵蓋上述每一類的項目比對輸出字面值
4. **AC-4**：`--due` 的值不是有效的 `YYYY-MM-DD` 日期（例如 `2026-13-01`、`12/5`）或缺值時，在 stderr 顯示錯誤、exit code 為 1，且 `todo.json` 不變 — 檢查方式：unittest 在暫存目錄執行後檢查 exit code 與檔案內容

- **核准日期**: 2026-11-25
- **核准來源**: 2026-11-25 使用者需求「待辦要能帶到期日。清單在有到期日的待辦後面顯示月/日；另外要能列出已經逾期、還沒完成的待辦。」；同日使用者看過 AC-1～AC-4 後回覆「照你的建議，全部核准。」（AC-1～AC-4）

## 風險與首要驗證

**風險**: Low — 無明顯未知，依一般相依順序實作與驗證。既有資料只有 `id`／`title`／`done` 三個欄位（由 `todo.py` 的 `add` 決定），沒有到期日欄位時維持原輸出由 AC-2 與既有測試保護。
