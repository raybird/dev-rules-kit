# Issue 3601 - 待辦到期日與逾期清單 (Small)

## 概述
待辦可以設定到期日。列出清單時，有到期日的待辦在標題後面顯示月/日；另外新增一個指令，列出已經逾期、還沒完成的待辦。沒有到期日的待辦與既有 `todo.json` 資料照原樣顯示。不做的事：修改或清除既有待辦的到期日、排序、提醒。

## 涉及檔案
- `todo.py` - `add` 接受到期日並存入 `due` 欄位；`render` 顯示月/日；新增逾期清單指令
- `test_todo.py` - 補上 AC-1～AC-4 的測試
- `README.md` - 常青文件：使用說明補上到期日與逾期指令（依 project.md 常青文件更新責任）

## 驗收條件

1. **AC-1**：執行 `python3 todo.py add 繳電費 --due 2026-12-05` 後，`python3 todo.py` 顯示 `[ ] 1. 繳電費 (12/5)`；`todo.json` 該筆存有 `"due": "2026-12-05"`。 — 檢查方式：單元測試驗 `render` 輸出字面值，加上在暫存目錄透過 `main` 執行 add 後讀回 `todo.json`
2. **AC-2**：沒有到期日的待辦，以及沒有 `due` 欄位的既有 `todo.json` 資料，顯示與現在相同，例如 `[ ] 2. 寫週報`。 — 檢查方式：既有 `test_render_marks_done` 保持綠燈，另測沒有 `due` 欄位的資料
3. **AC-3**：執行 `python3 todo.py overdue` 只列出「未完成且到期日早於今天（本機日期）」的待辦，格式同 AC-1；今天到期的、已完成的、沒有到期日的都不列；沒有符合的待辦時不輸出任何內容。 — 檢查方式：以固定的「今天」日期執行單元測試，涵蓋昨天到期、今天到期、已完成逾期、無到期日四種資料
4. **AC-4**：`--due` 給的不是有效的 `YYYY-MM-DD` 日期（例如 `2026-13-40`、`12/5`）時，stderr 顯示錯誤訊息、exit code 非 0，`todo.json` 不變。 — 檢查方式：單元測試在暫存目錄執行，比對執行前後 `todo.json` 並檢查結束碼

- **核准日期**: 2026-11-25
- **核准來源**: 2026-11-25 使用者要求「待辦要能帶到期日。清單在有到期日的待辦後面顯示月/日；另外要能列出已經逾期、還沒完成的待辦。」，涵蓋 AC-2；2026-11-25 使用者回覆「照你的建議，全部核准。」，接受 TBD-1～TBD-4 建議答案（TBD-1：AC-1、AC-4；TBD-2：AC-1、AC-3；TBD-3：AC-3；TBD-4：AC-4），涵蓋 AC-1、AC-3、AC-4
