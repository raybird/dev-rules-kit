# Issue 3101 - 新增 export 指令匯出 CSV (Small)

## 概述
為 `todo.py` 新增 `export` 指令，將待辦匯出成 CSV，欄位依序為 id、標題、完成狀態三欄。

## 涉及檔案
- `todo.py` - 新增 `export` 指令分支與 CSV 輸出
- `test_todo.py` - 新增 export 測試
- `README.md` - 使用說明補 `export` 指令（常青文件）

## 驗收條件

1. **AC-1**：`python3 todo.py export` 輸出 CSV，每筆待辦一列，欄位順序為 id、標題、完成狀態三欄 — 檢查方式：在暫存目錄建立含 2 筆待辦（1 筆已完成）的 `todo.json`，執行 export，以 `csv.reader` 解析後每列恰 3 欄且依序對應 id、title、done
2. **AC-2**：CSV 輸出到 stdout，不寫檔（使用者可用 `> todo.csv` 導向） — 檢查方式：執行 export 後 stdout 為 CSV 內容，工作目錄未新增檔案
3. **AC-3**：第一列為標頭 `id,title,done`；沒有待辦時只輸出標頭列 — 檢查方式：分別以 2 筆與空清單執行 export，比對第一列與總列數
4. **AC-4**：完成狀態輸出為 `true`／`false` — 檢查方式：已完成與未完成各一筆，比對第 3 欄字面值
5. **AC-5**：逗號分隔、依 RFC 4180 跳脫（標題含逗號、雙引號或換行時以雙引號包住，內部雙引號重複），UTF-8 無 BOM、換行為 `\n` — 檢查方式：標題為 `買牛奶, "低脂"` 時輸出 `1,"買牛奶, ""低脂""",false`，且 `csv.reader` 讀回的標題與原值相同

- **核准日期**: 2026-10-18（AC-1～AC-5 全部）
- **核准來源**: 使用者於 2026-10-18 `/new-issue` 原話：「幫 todo 加一個 export 指令，把待辦匯出成 CSV。欄位已確定是 id、標題、完成狀態三欄，順序就這樣。」涵蓋 AC-1。使用者於 2026-10-18 回覆逐題確認：「1. 輸出到 stdout；2. 要標題列；其他照建議」——第 1 題核准 AC-2（stdout）；第 2 題核准 AC-3 須有標頭列，標頭文字另於同日回覆「照建議」核准為 `id,title,done`；「其他照建議」核准第 3 題 AC-4（`true`／`false`）與第 4 題 AC-5（RFC 4180、UTF-8 無 BOM、`\n`）
