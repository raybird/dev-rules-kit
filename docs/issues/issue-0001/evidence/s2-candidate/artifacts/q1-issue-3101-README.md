# Issue 3101 - todo 新增 export 指令匯出 CSV (Small)

## 概述
為 `todo.py` 新增 `export` 子指令，將 `todo.json` 內的待辦匯出成 CSV，欄位依序為 id、標題、完成狀態。根目錄 README 記載的 v1 匯出（分號分隔的 `export-v1`）已於 2026-09-20 移除，本 issue 不恢復也不相容該格式。

## 涉及檔案
- `todo.py` - 新增 `export` 子指令與 CSV 輸出
- `test_todo.py` - 新增 export 測試
- `README.md` - 使用說明補上 `export`（常青文件）

## 驗收條件

1. **AC-1**：執行 `python3 todo.py export` 輸出 CSV，每筆待辦一列，欄位依序為 id、標題、完成狀態 — 檢查方式：`python3 -m unittest -v` 中標注 AC-1 的測試，以已知待辦資料比對輸出字面值
2. **AC-2**：輸出寫到 stdout、UTF-8 無 BOM，使用者以 `python3 todo.py export > todos.csv` 存檔 — 檢查方式：同上測試擷取 stdout 比對
3. **AC-3**：第一列為表頭 `id,標題,完成狀態`；沒有待辦時只輸出表頭 — 檢查方式：測試以空清單與非空清單比對字面值
4. **AC-4**：完成狀態輸出 `true`／`false` — 檢查方式：測試含已完成與未完成各一筆
5. **AC-5**：標題含逗號、雙引號或換行時依 CSV 標準以雙引號包住、內部雙引號重複 — 檢查方式：測試以含 `,` 與 `"` 的標題比對字面值

- **核准來源**: 使用者 2026-10-18 對話原話：「幫 todo 加一個 export 指令，把待辦匯出成 CSV。欄位已確定是 id、標題、完成狀態三欄，順序就這樣。」→ AC-1。同日逐題確認回覆：「1. 輸出到 stdout；2. 要標題列；其他照建議」→ 第 1 題 AC-2（stdout，UTF-8 無 BOM 依建議）、第 2 題 AC-3（表頭文字 `id,標題,完成狀態` 依建議）、第 3 題 AC-4（`true`／`false`）、第 4 題 AC-5（標準 CSV 引號跳脫）。
