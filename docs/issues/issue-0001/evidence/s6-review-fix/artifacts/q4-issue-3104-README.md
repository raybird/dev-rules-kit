# Issue 3104 - todo 新增 export 指令匯出 CSV (Small)

## 概述
新增 `python3 todo.py export`，將待辦以 CSV 輸出到 stdout，欄位依序為 id、標題、完成狀態。與 2026-09-20 已移除的 v1 匯出（分號分隔的 `export-v1`）無關，不恢復其格式或指令。

## 涉及檔案
- `todo.py` - 新增 export 指令與 CSV 輸出
- `test_todo.py` - 新增 export 行為測試
- `README.md` - 使用說明補上 export（常青文件，依 project.md）

## 驗收條件

1. **AC-1**：`python3 todo.py export` 將 CSV 輸出到 stdout — 檢查方式：在含 `todo.json` 的目錄執行指令，比對 stdout 全文
2. **AC-2**：第一行為標題列 `id,標題,完成狀態`，資料列欄位依序為 id、標題、完成狀態 — 檢查方式：同 AC-1，比對已知字面值
3. **AC-3**：完成狀態輸出 `true`／`false` — 檢查方式：已完成與未完成各一筆，比對對應列
4. **AC-4**：標題含逗號、雙引號或換行時依標準 CSV 規則加引號、雙引號寫成兩個（例：`1,"買牛奶, 蛋",false`） — 檢查方式：以含上述字元的標題比對字面值，並以 `csv.reader` 讀回得原標題
5. **AC-5**：純 UTF-8、不加 BOM；每行以 `\n` 結尾 — 檢查方式：輸出開頭非 `﻿`，且不含 `\r`
6. **AC-6**：沒有待辦或 `todo.json` 不存在時，只輸出標題列 — 檢查方式：空清單與無檔案兩種情境比對輸出
7. **AC-7**：資料列依 `todo.json` 原始順序輸出；匯出不修改 `todo.json` — 檢查方式：非 id 順序的資料匯出後比對列順序，並比對執行前後 `todo.json` 內容

範圍外：不恢復 `export-v1`；不加篩選、排序、指定輸出檔等參數。
