# Issue 3101 - todo export 匯出 CSV (Small)

## 概述
為 `todo.py` 新增 `export` 子指令，將 `todo.json` 內的待辦匯出成 CSV，欄位依序為 id、標題、完成狀態。

注意：根目錄 `README.md` 記載 2026-09-20 起已移除分號分隔的 `export-v1` 且不保留相容層；本 issue 是新的逗號分隔 CSV 匯出，不恢復 `export-v1`。

## 涉及檔案
- `todo.py` - 新增 CSV 輸出函式與 `export` 子指令分派
- `test_todo.py` - 新增 export 測試（標注 AC 編號）
- `README.md` - 使用說明補上 `export`（常青文件，依 project.md）

## 驗收條件

1. **AC-1**：`export` 為每筆待辦輸出一列，欄位順序固定為 id、標題、完成狀態，以逗號分隔 — 檢查方式：`python3 -m unittest -v` 中標注 AC-1 的測試，以含兩筆（一完成、一未完成）的固定資料比對輸出字面值
2. **AC-2**：輸出目的地為 stdout，使用者以 `python3 todo.py export > todos.csv` 存檔；不新增檔案路徑參數 — 檢查方式：標注 AC-2 的測試擷取 stdout 比對
3. **AC-3**：第一列為標題列 `id,title,done`；沒有待辦（含 `todo.json` 不存在）時只輸出標題列 — 檢查方式：標注 AC-3 的測試以空清單比對輸出
4. **AC-4**：完成狀態以 `true`／`false` 表示 — 檢查方式：AC-1 測試資料的兩筆分別比對 `true`、`false`
5. **AC-5**：標題含逗號、雙引號或換行時依標準 CSV 規則（RFC 4180）加雙引號並跳脫內部雙引號；輸出 UTF-8、無 BOM、換行為 `\n` — 檢查方式：標注 AC-5 的測試以標題 `買牛奶, "低脂"` 比對輸出 `1,"買牛奶, ""低脂""",false`

- **核准日期**: 2026-10-18
- **核准來源**: AC-1 — 使用者 2026-10-18 對話原話：「幫 todo 加一個 export 指令，把待辦匯出成 CSV。欄位已確定是 id、標題、完成狀態三欄，順序就這樣。」AC-2～AC-5 — 使用者 2026-10-18 回覆提問 Q1～Q4：「1. 輸出到 stdout；2. 要標題列；其他照建議」。Q1 → AC-2（stdout）；Q2 → AC-3（要標題列，標題列文字 `id,title,done` 與空清單只輸出標題列依「其他照建議」採建議內容）；Q3 → AC-4（`true`／`false`，照建議）；Q4 → AC-5（標準 CSV 引號、UTF-8 無 BOM、`\n` 換行，照建議）
