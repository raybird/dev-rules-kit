# Issue 3102 - 待辦到期提醒 (Small)

## 概述
每個待辦可設定到期時間（`YYYY-MM-DD HH:MM`，本機時間）。每次執行 todo 指令時檢查，未完成且已到期的項目在該指令原本輸出之前顯示提醒；不使用常駐程序。

不在本次範圍：清除／取消到期時間、時區設定、提前提醒。

## 涉及檔案
- `todo.py` - 新增 `due` 指令、到期時間顯示、到期檢查與提醒輸出、輸入錯誤處理
- `test_todo.py` - 新增各 AC 的測試
- `README.md` - 使用說明補 `due` 指令與提醒行為（常青文件）

## 驗收條件

1. **AC-1：設定與顯示到期時間** — `python3 todo.py due <id> <YYYY-MM-DD HH:MM>` 將該項目的到期時間寫入 `todo.json`；重複設定會覆蓋。列出時，有到期時間的項目在行尾加 `（到期 YYYY-MM-DD HH:MM）`，沒有的維持原格式（例如 `[ ] 2. 寫週報（到期 2026-10-18 09:00）`）。 — 檢查方式：`python3 -m unittest -v` 中對應 AC-1 的測試；既有 `test_render_marks_done` 維持通過
2. **AC-2：輸入錯誤** — 時間不符合 `YYYY-MM-DD HH:MM`，或 id 不存在時，stderr 輸出錯誤訊息、exit code 非 0，`todo.json` 內容不變。 — 檢查方式：`python3 -m unittest -v` 中對應 AC-2 的測試（格式錯誤、id 不存在各一）
3. **AC-3：執行指令時的到期提醒** — 執行 `add`、`done` 或列出時，每個「未完成且目前時間 ≥ 到期時間」的項目輸出一行 `⏰ 已到期：<id>. <標題>（到期 YYYY-MM-DD HH:MM）`，位於該指令原本輸出之前；每次執行都重複提醒；已完成或尚未到期的項目不提醒；目前時間恰等於到期時間時提醒。 — 檢查方式：`python3 -m unittest -v` 中對應 AC-3 的測試，以固定的目前時間驗證到期、未到期、恰到期、已完成與輸出順序
4. **AC-4：無到期項目與舊資料** — 沒有到期項目時，不輸出任何額外內容；舊 `todo.json` 中沒有到期時間的項目照常列出、完成，不提醒也不報錯。 — 檢查方式：`python3 -m unittest -v` 中對應 AC-4 的測試，以不含到期欄位的資料執行列出與 `done`
