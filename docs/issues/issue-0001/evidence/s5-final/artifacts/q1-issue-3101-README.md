# Issue 3101 - todo 新增 export 指令匯出 CSV (Small)

## 概述
在 `todo.py` 加上 `export` 子指令，把 `todo.json` 內的待辦匯出成 CSV，欄位依序為 id、標題、完成狀態。目前 `todo.py export` 會落入預設分支、直接列出待辦；本 issue 讓它改為輸出 CSV。2026-09-20 已移除的 v1 匯出（`export-v1`，分號分隔）不恢復、不做相容。

## 涉及檔案
- `todo.py` - 新增 export 子指令與 CSV 輸出
- `test_todo.py` - 新增 export 的單元測試
- `README.md` - 使用說明補上 `export`（常青文件，依 project.md）

## 驗收條件

1. **AC-1**：執行 `python3 todo.py export` 時輸出 CSV，每筆待辦一列、依 `todo.json` 內順序，欄位依序為 id、標題、完成狀態三欄，不含其他欄位 — 檢查方式：`python3 -m unittest -v` 中以已知待辦資料比對輸出的字面值
2. **AC-2**：輸出到標準輸出，不寫檔，使用者自行以 `> todos.csv` 導向 — 檢查方式：單元測試擷取 stdout 比對字面值
3. **AC-3**：第一列為標題列 `id,標題,完成狀態` — 檢查方式：單元測試比對輸出第一列
4. **AC-4**：完成狀態以 `true`／`false` 表示 — 檢查方式：單元測試以一筆已完成、一筆未完成的資料比對
5. **AC-5**：逗號分隔，依 RFC 4180 處理跳脫：標題含逗號、雙引號或換行時以雙引號包住，內部雙引號重複為 `""` — 檢查方式：單元測試以含 `,` 與 `"` 的標題比對字面值
6. **AC-6**：以 UTF-8（不含 BOM）輸出，中文標題原樣保留 — 檢查方式：單元測試以中文標題比對輸出
7. **AC-7**：沒有任何待辦（含 `todo.json` 不存在）時只輸出標題列，exit code 0 — 檢查方式：單元測試以空清單比對
